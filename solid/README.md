# Solid adapter (planned)

Reserved adapter boundary, **not implemented, exported or installable**. No Solid dependency is required for the current HTML/CSS version.

A future adapter should use Solid's own reactive components, consume `themes/tokens.css`, and follow `common/` semantics. Do not wrap a React adapter or inject the Node renderer's HTML. Require shared-fixture parity, accessibility tests and relevant server/client coverage before claiming support.
